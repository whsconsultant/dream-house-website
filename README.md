# Dream House — Full-Floor Penthouse

Interactive WebGL walkthrough of a **12,400 sq ft** full-floor penthouse: great room, dining, kitchen, media lounge, library, master suite + spa, guest wing, and an infinity-pool terrace over a night city skyline.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

Site path: `https://<user>.github.io/dream-house-website/`

## Controls

- **Enter the penthouse** — first-person walk (WASD + mouse)
- **Orbit view** — cinematic orbit camera
- **E / Q** — next / previous room
- Room list — teleport to any zone
